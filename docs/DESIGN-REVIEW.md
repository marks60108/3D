# 全模板設計審查紀錄(2026-07)

對全部 14 個模板做的一次系統性審查。原則:只修「會影響列印成敗或使用安全」的問題,不為改而改。所有修改後,**14 個模板的預設輸出與審查前逐位元一致**(用 `npm run verify` 的三角形數/尺寸比對),確定沒有意外改到既有行為。

## 修了什麼

### 1. 重複程式碼整併(不影響幾何)

`buildStrut`(連接臂)在風扇支架三個模板各複製一份、2D 工具(圓角矩形/橢圓/兔耳/梯形/排版)只存在娃娃椅檔案裡。全部抽到共用的 `src/templates/geo.ts`,之後新模板直接引用,改一處生效三處。

### 2. 極端參數防呆(每一項都加了迴歸測試)

使用者把滑桿拉到極端組合時,原本可能產生「印不出來或印了不能用」的幾何。逐一加了防呆鉗制(clamp):

| 模板 | 問題 | 修法 |
|---|---|---|
| 圓柱/套筒 | 內徑 ≥ 外徑 → 整支被挖空消失 | 內徑自動鉗制,永遠保留 ≥0.4mm 壁厚 |
| 收納盒 | 底板厚度 > 盒高 → 空腔反轉出錯;蓋子卡榫深過內腔 | 底板 ≤ 盒高−1;卡榫深 ≤ 內腔深 |
| L型支架 | 孔位內縮 > 臂長 → 鎖孔跑到零件外面(沒孔) | 孔位自動鉗制在臂內、離邊 ≥1.5mm |
| DIMM 壓桿 | 漏斗口比主體寬 → 夾槽兩壁消失、完全失去保持力;斜切量比握把大 → 握把被切光 | 槽口 ≤ 主體寬−1.2mm 且永不窄於深處寬(避免反向漏斗);斜切 ≤ 握把一半 |
| 風扇支架骨架 | T 型滑槽頸+頭深度 > 軌道厚 → 滑槽打穿頂,腳直接掉出來;頭寬 ≥ 外框寬 → 側壁消失 | 保證滑槽頂保留 ≥1.2mm、側壁 ≥1mm |
| 設備托高架 | 支腳兩軸同時往內拉超過框寬 → 腳與框架完全分離,印出來是一支飄在半空的獨立柱子 | 偵測「兩軸都脫離框帶」時,自動把較近的一軸拉回接觸位置(用 decompose 驗證過極端值下仍為單一實體) |
| 吊飾展示板 | 卡榫寬 > 邊界留白 → 卡榫凸出板角 | 卡榫/凹槽位置自動收進板邊內 |
| 餐桌椅/搖椅 | 尺寸調很小時,裝飾鏤空會把腳架切碎 | 尺寸低於安全門檻時自動略過鏤空(結構優先於造型) |

### 3. 迴歸測試強化

`scripts/verify-templates.ts` 新增「extreme-value guards」區:上表每一項防呆都有一筆極端參數測試,`npm run verify` 一次跑完(預設 14 筆 + 變體 12 筆 + 極端 8 筆)。以後改模板跑一下就知道有沒有弄壞什麼。

## 審查過但不改的(記錄原因)

- **風扇支架(基本/強化版)腳偏移**:不會有托高架的分離問題,因為每支腳都有放射臂跟著,天然保持連接。
- **散熱托盤(M60)**:上一輪已改成裙牆落地免支撐,`restHeight` 已有鉗制,無新問題。
- **壁掛掛勾**:`armStartZ` 已有鉗制;末端球頭在 0°~120° 全範圍驗證過。
- **風扇支架腳(排版列印)**:卡榫尺寸由滑槽參數減去餘裕推導,參數範圍內不會變負。
- **自訂堆疊模式**:使用者本來就有完全自由(包括做出分離件),不加限制是刻意的。
- **效能**:最重的模板(吊飾板 ~4900 三角形)在瀏覽器即時預覽毫無壓力,不需優化。

## 已知限制(非缺陷,設計取捨)

- 圓角一律用斜切或 hull 圓柱逼近,引擎無真正的 3D fillet。
- 搖椅吊桿與頂樑共面,擺動方向是左右而非前後(玩具展示用途可接受,做真前後擺需要立體交叉結構,列印複雜度不成比例)。
- 餐盤固定方式從原品的側邊鉚釘改為插背板孔(3mm FDM 板做不了可靠的微型鉚釘鉸鏈)。

## 後續修正:餐桌椅組裝失敗(2026-07,追加)

**問題**:餐桌椅實際印出來組不起來——榫頭與卡槽在 3D 對位後根本沒對齊,而且造型也不像使用者提供的參考照片。

**根因(重要教訓)**:上一版「驗證」只確認每個零件能算出有效 manifold、能顯示,**完全沒驗證各零件依組裝姿態擺到 3D 空間後榫槽真的對得上**。零件有效 ≠ 組得起來,這兩件事被當成同一件,是這次審查最大的盲點。

**修法**:
1. 餐桌椅整個重新設計,造型貼近參考(圓弧殼背板+兔耳+橢圓握把孔、外撇腳、前方附圍邊餐盤)。
2. 改用「全部插入座板」的榫接系統:背板下榫、腳頂榫、餐盤前緣舌榫全部進座板的槽,榫厚=板厚,槽=榫+餘裕,位置由共用變數推導保證兩邊一致。
3. **新增「組裝預覽」開關**:每個零件都定義了「平放列印姿態」+「組裝姿態(旋轉+平移)」,開關打開就把零件依組裝姿態擺好 union 起來,直接在工具裡看到組好的樣子。這樣使用者(跟我)能在列印前確認榫槽對得上,而不是拿實際列印去試錯。
4. 用組裝預覽渲染實際確認:背板站正、腳撐住座板、餐盤舌榫入槽,全部對位。

**待辦**:搖椅(doll-swing)有同樣的「宣稱能組裝但未經組裝驗證」風險,尚未用同一套方法重驗,需要比照處理。
