# P2S 3D 建模工具

給拓竹 P2S(列印範圍 256×256×256mm)使用的網頁參數化建模工具。用滑桿調整尺寸、即時看 3D 預覽,滿意後直接下載 STL 匯入 Bambu Studio 列印。

**線上使用**:https://marks60108.github.io/3D/(不用安裝任何東西,瀏覽器打開就能用)

開發過程的里程碑與每次抓到的真實錯誤見 [CHANGELOG.md](CHANGELOG.md);每個模板的設計細節與稽核紀錄見 [docs/DESIGN-REVIEW.md](docs/DESIGN-REVIEW.md)。原創迷你家具系列的上市規劃書(品牌定位、成本試算、包裝、通路、法遵、90 天路線圖)見 [docs/BUSINESS-PLAN.html](docs/BUSINESS-PLAN.html)。

## 開發

```bash
npm install
npm run dev       # 啟動本機開發伺服器
npm run build     # 打包 production build
npm run verify    # 在 Node 中驗證所有模板都能正確產生幾何(不用開瀏覽器)
```

推上 `claude/3d-printing-modeling-1vuxuo` 分支會透過 GitHub Actions 自動建置並部署到 GitHub Pages。

## 功能

### 模板模式

每個模板都用滑桿/數字輸入調整尺寸、孔位等參數,即時更新 3D 預覽:

#### 伺服器 / 機殼散熱

- **風扇架高支架 Fan Riser Mount**:風扇鎖孔環透過 4 條放射狀連接臂延伸到外圍支撐腳,支架整體跨距可獨立於風扇尺寸放大,4 支腳位置各自可微調以避開障礙物,中間鏤空不擋風。
- **風扇架高支架(強化外框版)**:同上,額外沿支撐腳外圍加一圈可調寬度的框把 4 支腳連起來,加強大跨距時的剛性。
- **風扇支架骨架/腳(分件版)**:骨架用 T 型滑槽配合可拆式腳,腳可一次排版列印多支、與骨架用 T 型卡榫組裝,方便分色或大量列印備用腳。
- **DIMM 記憶體安裝壓桿**:只在模組兩端做卡緣夾槽(咬住 PCB 邊緣本身,不壓在板面上),中間懸空避開 RCD/資料緩衝晶片,雙手均勻施力就能把模組壓進插槽。
- **路由器/網通設備托高架 Device Riser**:把長方形設備(路由器、Mesh 節點等)架高的開放式框架,4 支腳位置可個別微調,設備靠自身重量放在框上。
- **路由器散熱托盤(M60)**:矮托盤式底座,鏤空格柵+側面通風窗,圍牆直落桌面免支撐,「架高高度」可調(0=貼桌)。

#### 收納 / 展示(通用)

- **收納盒 Container**:開口收納盒,可選壓入式蓋子(附卡榫)。
- **壁掛掛勾 Wall Hook**:背板含鎖孔,向外伸出、末端上翹的掛勾。
- **吊飾排勾展示板 Charm Display Panel**:可組合的排孔展示板,掛勾間距/排數可調,板與板之間可用卡榫連接件拼接成更大面板。

#### 原創迷你家具系列(北歐簡約風・無角色元素・可商用)

給小型收藏公仔/娃娃(約 10cm 高)用的迷你家具,全部鍵型方榫防轉、免膠可拆裝組裝,共用同一套裝飾語言(圓角、三孔裝飾)。每款都通過 `npm run verify` 的零干涉組裝稽核(見下方「技術」)。8 款目前都已上線,設計動機、每一處接合抓到的實際錯誤與修法都記在 [docs/DESIGN-REVIEW.md](docs/DESIGN-REVIEW.md):

- **迷你床 Mini Doll Bed**:7 件式,床墊平台+4 支錐形腳+床頭板/床尾板,全平放/直立列印免支撐。
- **迷你桌 Mini Doll Table**:2 件式,圓角桌面+4 支錐形腳。
- **迷你椅 Mini Doll Chair**:3 件式,圓角座面+三孔裝飾靠背+4 支錐形腳。
- **迷你收納櫃 Mini Doll Shelf**:5 件式,底板+左右側板+頂板+背板,開放式無門片、結構最穩固。
- **迷你衣櫃 Mini Doll Wardrobe**:5 件式,收納櫃榫接櫃體放大加高+掛衣圓桿(兩端插榫)。開放式無門片——摩擦卡榫門片需要實機測試印表機公差才能定案,目前刻意不做。
- **迷你穿衣鏡框 Mini Doll Mirror Frame**:2 件式,圓角外框挖窗+插榫底座。FDM 印不出鏡面,窗口是空的,自己貼亮面卡片/反光貼紙當鏡面。
- **迷你邊桌 Mini Doll Side Table**:4 件式,收納櫃側板卡榫模組延伸成三層(底/中/頂),四面開放無背板。
- **迷你壁掛層板 Mini Wall Shelf**:2 件式,壁掛背板(鎖真實牆壁用,跟壁掛掛勾同一套鎖孔規格)+層板掛上兩支水平插銷。唯一鎖在使用者自己真實牆壁上的一款,不是娃娃屋內部家具。

#### 吉伊卡哇同人道具(個人使用/送禮・**非商用**)

以下兩款外形明確指涉吉伊卡哇烏薩奇角色,僅供個人使用或送禮,**不要商用販售**(商用請改用上方的原創家具系列):

- **餐桌椅(兔耳娃娃椅・分件列印)**:娃娃餐椅 5 分件(背板兔耳+橢圓孔、座板、左右腳架、圍邊餐盤),卡榫組裝、可分色列印,每件可單獨勾選匯出。
- **搖椅(兔耳娃娃鞦韆・分件列印)**:娃娃盪鞦韆搖椅 8 分件(兔耳頂樑+插銷、弧底搖腳、吊桿、座板、固定扣),吊桿套插銷可微幅擺動,搖腳圓弧可前後搖。
- **烏薩奇臉權杖**:長柄武器道具,圓球白臉頭+彈簧+握柄,彈簧樣式可選(免支撐螺紋柱/硬螺旋/塞真彈簧/可動 PLA 螺旋),可整支對半分印免支撐。
- **彈簧毛絨球(組裝件)**:模組化三件(臉球+彈簧段+握柄),插銷對插組裝、分色分印,預設 40mm 球+120mm 柄。

#### 通用幾何

- **L 型支架 Bracket**:L 型轉接支架,兩側可挖 1~2 個鎖孔。
- **圓柱/套筒 Cylinder & Tube**:實心圓柱,或挖空成套筒(貫穿孔或盲孔)。

### 自訂堆疊模式

自行疊加方塊/圓柱,指定位置、旋轉與聯集/差集運算,組出模板沒有涵蓋的形狀。

### 通用功能

- **儲存/讀取設定**:調好的參數可以命名存在瀏覽器本機(localStorage),之後一鍵叫回,不用每次重調。
- **參數分組收合**:參數多的模板會把「微調 / 進階」參數收進可收合的區塊,常用的擺前面。
- **模板分類**:下拉選單依用途分成「伺服器 / 機殼散熱」「收納 / 展示」「通用幾何」。
- **重置**:一鍵把目前模板回到預設值。
- **手機可用**:窄螢幕時面板與 3D 預覽自動改為上下排列。
- 3D 預覽會畫出 P2S 的 256mm³ 列印範圍框線,超出範圍時框線變紅並顯示警告。
- 下載的 STL 座標原點對齊列印範圍角落,方便直接匯入切片軟體。
- 模型擺放角度(躺平、立起來等)請在 Bambu Studio 裡用「貼合底面」等工具調整,這裡只負責產生正確尺寸的模型。

## 技術

Vite + React + TypeScript,3D 渲染用 `@react-three/fiber`(Three.js),實體布林運算(挖孔、合併)用 [manifold-3d](https://github.com/elalish/manifold) 的 WASM 版本,STL 匯出用 `three-stdlib` 的 `STLExporter`。

新增模板的方式:在 `src/templates/` 建立一個檔案,依照 `types.ts` 的 `Template` 介面定義參數與 `build()` 函式,再到 `src/templates/index.ts` 註冊。共用的幾何工具(連接臂、圓角矩形、兔耳、分件排版等)在 `src/templates/geo.ts`。建議加完模板後在 `scripts/verify-templates.ts` 補一筆驗證,執行 `npm run verify` 確認幾何正確(無需開瀏覽器)。

**多分件模板的組裝驗證**:凡是有「組裝預覽」開關、榫接組裝的多分件模板(娃娃家具、餐桌椅等),光是每個零件能算出有效 manifold 還不夠——零件有效不等於組得起來。`scripts/verify-templates.ts` 對這類模板另外做「零干涉稽核」:在組裝姿態下量測兩個零件的 `Vol(A) + Vol(B) − Vol(A∪B)`,應該接近 0(真的干涉是幾百 mm³,<30mm³ 算分面誤差);再把餘裕改成負值(榫故意做大)重複同一個量測,重疊必須明顯變大,證明榫真的插進孔裡而不是剛好對不上。**這個數值稽核只驗證「兩個零件彼此對不對得上」,驗證不出「整組東西的絕對方向合不合理」**——曾經真的發生過插銷跟插槽兩邊座標算法用同一套錯誤假設互相對齊、稽核顯示全過,但背板實際上整片攤平在地上沒有立起來的案例。所以每個新的多分件模板,除了跑 `npm run verify`,還要用 Playwright(或手動)在瀏覽器裡打開「組裝預覽」實際看一次渲染結果,兩者缺一不可。
